# Yarnix Labs

## Project Summary
Yarnix Labs builds cutting-edge AI and software solutions for modern businesses. Expert AI development, custom web applications, automation, and DevOps services.

## Technologies
- **Frontend**: React, Vite, Tailwind CSS, shadcn-ui
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **CMS**: Sanity (planned/integrated)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment
This project is configured for deployment with Vercel and other modern hosting platforms.
